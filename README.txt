PROJECT DESCRIPTION:
SkyTrack is a weather tracking application
that retrieves real-time weather information
using the OpenWeatherMap API.

API USED:
OpenWeatherMap API

API DOCUMENTATION:
https://openweathermap.org/api

TECHNOLOGIES:
HTML5
CSS3
JavaScript
Fetch API
JSON

FILES INCLUDED:
index.html
app.html
styles.css
script.js
README.txt
images/

FUNCTIONS:
Search weather by city
Display temperature
Display humidity
Display wind speed
Display weather description
Error handling

HOW TO RUN:
1. Create OpenWeatherMap account.
2. Generate API Key.
3. Replace YOUR_API_KEY in script.js.
4. Open index.html.
5. Launch Weather Application.
6. Search any city.
